## 作品名稱

**Analyze_scores**

## 我要解決的問題

用 Python 來解決問題，把成績資料寫進程式裡，程式就能自動幫我們算出各項統計數據，包括：最高分、最低分、平均、前三名成績、及格人數與及格率，以及高於平均的分數清單。

## 使用到的 Python 技術

### 資料結構

- **List（串列）**：用來存放成績資料，例如 `scores = [78, 92, 65, 88, ...]`。

### 內建函式

- `max()`：找出串列中的最大值（最高分）。
- `min()`：找出串列中的最小值（最低分）。
- `sum()`：計算串列所有元素的總和，用來算平均。
- `len()`：取得串列的長度（資料筆數）。
- `sorted()`：將串列排序，搭配 `reverse=True` 參數可由大到小排序。

### 切片（Slicing）

- 利用切片取得串列的子集合，例如 `sorted(scores, reverse=True)[:3]` 取前三名，`store[-1:-4:-1]` 取倒數三筆資料。

### 基本語法

- **變數指派**：將計算結果存入變數。
- **算術運算**：加減乘除與百分比計算。
- **`print()` 輸出**：將結果印出到螢幕。


## 我遇到的問題與如何解決

### 1. sorted() 與 reverse 參數

使用 `sorted()` 時，預設是由小到大排序。需要加上 `reverse=True` 才能由大到小排列。這個參數的記憶一開始容易搞混。

**解決方式**：在程式碼中加入註解 `# reverse=True→由大到大排序, [:3]→取3名` 作為提醒，避免之後忘記。

### 2. 切片的索引號

`01.py` 中的 `store[-1:-4:-1]` 這種負數索引搭配負間隔的寫法，一開始不太理解其含義。

**解決方式**：透過執行結果觀察 `[10, 20, 30]` 的輸出，逐步理解負數索引是從尾端往前數，負間隔表示反向取值。
