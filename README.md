## 第一週 (W1)：Class Score Analyzer

第一週的主題是**成績分析器**，用 Python 自動計算全班成績的各項統計數據，解決老師人工計算費時又容易出錯的問題。

### 專案檔案

| 檔案 | 說明 |
|------|------|
| `00.py` | Hello World 程式，測試環境是否正常運作 |
| `01.py` | 列表切片（Slicing）練習 |
| `02.py` | 成績分析主程式（最高分、最低分、平均、前三名、及格率） |
| `main_0909.py` | 進階分析，篩選高於平均的分數並建立排行榜 |

### 使用到的 Python 技術

- **資料結構**：List（串列）存放成績資料
- **內建函式**：`max()`、`min()`、`sum()`、`len()`、`sorted()`
- **列表推導式**：一行程式碼完成資料篩選，如 `[s for s in scores if s >= 60]`
- **切片（Slicing）**：`sorted(scores, reverse=True)[:3]` 取前三名
- **基本語法**：變數指派、算術運算、`print()` 輸出

### 學到的觀念

- 理解 List 的建立與操作，知道它是可變的資料結構
- 學會用內建函式快速處理資料，不用自己寫迴圈
- 學會把大問題拆解成小步驟（最高分 → 最低分 → 平均 → 排名 → 及格率）
- 養成在程式碼中寫註解的好習慣
