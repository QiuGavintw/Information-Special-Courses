## 統計數據

在課堂上，老師經常需要快速分析全班成績，例如：最高分、最低分、平均分、前幾名是誰、有多少人及格等。如果用人工計算，不僅費時也容易出錯。

這個作品利用 Python 來解決這個問題。只要把成績資料寫進程式裡，程式就能自動幫我們算出各項統計數據，包括：最高分、最低分、平均、前三名成績、及格人數與及格率，以及高於平均的分數清單和排行榜。這讓成績分析變得又快又準確。
