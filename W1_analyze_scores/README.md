# Analyze_scores

## 作品名稱

**Analyze_scores**

## 我要解決的問題

在課堂上，老師經常需要快速分析全班成績，例如：最高分、最低分、平均分、前幾名是誰、有多少人及格等。如果用人工計算，不僅費時也容易出錯。

這個作品利用 Python 來解決這個問題。只要把成績資料寫進程式裡，程式就能自動幫我們算出各項統計數據，包括：最高分、最低分、平均、前三名成績、及格人數與及格率，以及高於平均的分數清單和排行榜。這讓成績分析變得又快又準確。

## 使用到的 Python 技術

### 資料結構

- **List（串列）**：用來存放成績資料，例如 `scores = [78, 92, 65, 88, ...]`。

### 內建函式

- `max()`：找出串列中的最大值（最高分）。
- `min()`：找出串列中的最小值（最低分）。
- `sum()`：計算串列所有元素的總和，用來算平均。
- `len()`：取得串列的長度（資料筆數）。
- `sorted()`：將串列排序，搭配 `reverse=True` 參數可由大到小排序。

### 列表推導式（List Comprehension）

- 用來篩選資料，例如取出及格的成績 `[s for s in scores if s >= 60]`，以及取出高於平均的分數 `[score for score in scores if score > average]`。

### 切片（Slicing）

- 利用切片取得串列的子集合，例如 `sorted(scores, reverse=True)[:3]` 取前三名，`store[-1:-4:-1]` 取倒數三筆資料。

### 基本語法

- **變數指派**：將計算結果存入變數。
- **算術運算**：加減乘除與百分比計算。
- **`print()` 輸出**：將結果印出到螢幕。

### 專案中未使用的技術

本專案沒有使用到檔案讀寫、例外處理（try/except）、自訂函式、類別（class）、迴圈（for/while 迴圈僅出現在列表推導式中）、或任何外部套件。所有功能皆以 Python 基礎語法完成。

## 我遇到的問題與如何解決

### 1. 列表推導式的語法理解

剛接觸列表推導式時，對於 `[s for s in scores if s >= 60]` 這種一行就能完成篩選的寫法不太熟悉。透過實際寫出 `passed` 串列並觀察結果，慢慢理解了推導式的結構：前面是表達式，後面是條件判斷。

**解決方式**：實際動手修改條件值（例如把 60 改成 70），觀察輸出結果的變化，從而理解推導式的運作邏輯。

### 2. sorted() 與 reverse 參數

使用 `sorted()` 時，預設是由小到大排序。需要加上 `reverse=True` 才能由大到小排列。這個參數的記憶一開始容易搞混。

**解決方式**：在程式碼中加入註解 `# reverse=True→由大到大排序, [:3]→取3名` 作為提醒，避免之後忘記。

### 3. 切片的索引邏輯

`01.py` 中的 `store[-1:-4:-1]` 這種負數索引搭配負間隔的寫法，一開始不太理解其含義。

**解決方式**：透過執行結果觀察 `[10, 20, 30]` 的輸出，逐步理解負數索引是從尾端往前數，負間隔表示反向取值。

> **備註**：以上問題是根據程式碼中的註解與實際寫法推斷可能遇到的學習障礙。由於專案中沒有留下開發過程的紀錄，無法從目前專案內容確認實際遇到的具體問題。
